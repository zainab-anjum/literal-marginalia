# literal-marginalia

> A reading-first annotation tool for expressive digital marginalia.

---

## Why I made this

I love annotating physical books.

Not just highlighting passages or writing notes, but leaving weird little evidences of having actually read the book:

* *"FAAA"*
* *"bruh"*
* *"ew"*
* Arrows pointing at ridiculous sentences
* Tiny doodles in the margins
* Conversations with characters
* Arguments with the author
* Random stars, flowers, and hearts
* Increasingly aggressive annotations as the plot deteriorates
* Pictures of my cats reacting to the book
* Critical analyses of themes, characters, and the plot
* Predictions

Most ebook readers reduce this to **highlighting + typed notes**.

I wanted something closer to the physical experience of marginalia without turning the reading experience into a full-blown design editor.

So I started building one.

---

## What is it?

**Literal Marginalia** is a PDF-based reading and annotation tool focused on expressive but lightweight annotation.

### Features (Current & Planned)

* Multi-colour text highlighting
* Handwriting-style text
* Rotatable text annotations
* Speech bubbles
* Freehand drawing
* Doodles and decorative marks
* Custom image stickers
* Personal sticker library
* Drawing grids
* Annotation persistence
* Invertible annotation elements
* Annotated-book export

### Design Principle

> **The book stays the book. The annotations stay marginalia. And Zainab stays happy.**

---

## Development

This is an **AI-assisted development project**.

I'm building the application iteratively using AI coding tools, while defining the product requirements, testing the generated implementation, identifying edge cases, debugging failures, and refining the interaction design.

The project is deliberately being developed in small iterations rather than attempting to build the complete feature set at once.
